# CalcOil (სატესტო ვერსია)

Loading Master-ის სამუშაო ინსტრუმენტი (PWA, ტელეფონზე offline): გემის ტანკების გაზომვა OBQ/Final ან Initial/ROB, ნაპირის რეზერვუარები და B/L, Excel ullage report მეილით. შიგნით — ნავთობის რაოდენობის გამოთვლა: VCF, GSV, MT ვაკუუმში და ჰაერში, LT და bbl @ 60 °F, სამი სტანდარტი ერთმანეთის გვერდით.

## როგორ მუშაობს

- **ოპერაციები** — ერთი გემის ერთი შემოსვლა. ოპერაციის გვერდზე ნაბიჯებია სტატუსით: ტვირთი (მარკა, სიმკვრივე) → OBQ / Initial → Final / ROB → ნაპირი და B/L → რაპორტი. ყვითლად მონიშნულია შემდეგი ნაბიჯი.
- **ეტაპი** (OBQ, Final…) — წყალშიგი, ტრიმი, კრენი და ტანკების გეგმა (ცხვირი ზემოთ, Port წითელი, Starboard მწვანე). „დარჩენილი ტანკები ცარიელია“ — ერთი ღილაკით.
- **ტანკი** — „გემბანზე“ (ORH, ullage 2–5 ანათვალი, ტემპერატურა დონეებით, წყალი) და „ცხრილებიდან“ (trim/list შესწორება, TOV ცხრილის ორი სტრიქონიდან ან ხელით, FW). ქვემოთ ‹ › შემდეგ ტანკზე, ცოცხალი MT.
- **ნაპირი** — რეზერვუარები მანამდე/შემდეგ → B/L ავტომატურად, ან B/L ხელით; VEF; Ship/B/L.
- **რაპორტი** — Excel ტერმინალის ფორმატში, მეილით (Mail/Gmail) ან ფაილად.
- **გემები** — ტანკების განლაგება და RH; **დაშვება** — სწრაფი კალკულატორი; **პარამეტრები** — ენა, თემა, ნაგულისხმევები, სარეზერვო ფაილი.

| რეჟიმი | რას ითვლის |
| --- | --- |
| API MPMS 11.1-2004 = ГОСТ 3900-2022 | თანამედროვე ალგორითმი (ГОСТ 33335). ერთი workflow 611–1164 კგ/მ³-ზე: ნედლი ნავთობი, პროდუქტები, საპოხი ზეთები |
| ASTM D1250-80 (54A/54B) | იგივე, რასაც ახლანდელი Ullage Excel ითვლის (სწორი საზღვრებით) |
| ГОСТ 3900-85 | γ ცხრილი, ρt = ρ20 − γ(t − 20), მხოლოდ 0.6900–0.9999 გ/სმ³ |

სიმკვრივის წყარო: ρ15 ან ρ20 ლაბორატორიიდან, ციფრული მრიცხველით t-ზე, ან არეომეტრი (15 °C — ASTM D1298, 20 °C — ГОСТ 3900-2022 K = 1 − 0.000025(t − 20)).

## გაშვება

```bash
npm install
npm test            # 69 ტესტი: საკონტროლო მნიშვნელობები, გაზომვის წესები, რაპორტი, მარშრუტები
npm run dev
npm run build       # dist/ — PWA (service worker, offline; ახალი ვერსია ფონში იტვირთება და „განახლება“ ზოლით ირთვება)

```

## საკონტროლო მნიშვნელობები (`src/core/core.test.ts`)

- API MPMS 11.1 Addendum 2 (2019), Appendix G: jet fuel 11.1.7.3 Ex 4, crude 11.1.7.2 Ex 3, gasoline 11.1.6.1 Ex 6 — 11–12 ნიშნამდე ემთხვევა.
- ASTM D1298-12b Ex 2: crude, 858.29 @ 25 °C → 865.21 კგ/მ³.
- ГОСТ 3900-2022: ცხრილი A.1 (830.0 @ 12/13 °C) და §4.6.7-ის მაგალითი (830.9 @ 12.3 °C → 825.2).
- Ullage Excel: VCF 1.00358 / 1.00827 / 1.00944, STAR 10 MT vac 4890.87, MT air 4883.56, ГОСТ 4888.64.
- Table 54B ნაბეჭდი: 816.0 @ 34 °C → 0.9830, 865.0 @ 29 °C → 0.9886.

## ინტერფეისი

- სტანდარტის არჩევა = შედარების ცხრილი: შედეგის პანელში სამივე სტანდარტის ტონაჟი და სხვაობა API 2004-თან ჩანს, არჩეული სტანდარტი მთავარ ციფრს ცვლის.
- გრადუირებული სკალა აჩვენებს, რამდენი ტონით შორდება თითოეული სტანდარტი API 2004-ს.
- პარამეტრები: თემა (სისტემის / ღია / მუქი — ღამის ცვლისთვის) და ენა (ქართული / Русский / English).
- შრიფტი: FiraGO (bBox Type, SIL OFL 1.1) — ქართული, კირილიცა, ლათინური; ჩაშენებულია, offline-იც მუშაობს.

## სტრუქტურა

- `src/core/api2004.ts` — CTL, ρ60, ჯგუფები, 15/20 °C ბაზა
- `src/core/astm1980.ts` — Tables 53/54 A/B
- `src/core/gost85.ts` — γ ცხრილი
- `src/core/units.ts` — არეომეტრის შესწორება, ჰაერში წონა, LT, bbl
- `src/core/calc.ts` — სიმკვრივის გარდაქმნა და ტანკების ჯაჭვი
- `src/core/ship.ts` — ullage-ის წესები (API 3.1A), ტემპერატურის დონეები, TOV ინტერპოლაცია, OBQ/Final, Ship/B/L
- `src/report/` — XLSX writer და ullage report, გაზიარება მეილით
- `src/app/` — store (localStorage `calcoil-v2`, ძველი ვერსიებიდან მიგრაცია), hash router, deriveJob, სტრიქონები
- `src/screens/` — ეკრანები: Jobs, Job, Cargo, Stage, Tank, Shore, Report, Vessels, Calc, Settings
- `src/ui/` — AppBar/TabBar/StepRow, ShipPlan, HullMini, Readout, Segmented, Field, Num, Ruler, Sheet, Icons
- `src/i18n.ts`, `src/ship/strings.ts`, `src/theme.ts` — ენები და თემა

წნევის შესწორება (CPL) და LPG არ შედის. ოფიციალურ დოკუმენტებში გამოყენებამდე შეადარე სერტიფიცირებულ პროგრამას.
